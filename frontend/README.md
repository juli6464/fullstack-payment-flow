# Fullstack Payment Flow - Frontend

Frontend application developed with **React**, **TypeScript**, **Vite**, and **Material UI** for the Fullstack Payment Flow technical challenge.

---

# Tech Stack

- React
- TypeScript
- Vite
- React Router
- Axios
- Material UI
- React Hook Form
- Zod
- Vitest

---

# Features

- Product catalog
- Checkout flow
- Payment form
- Wompi payment integration
- Responsive UI
- Form validation
- API integration
- Unit testing

---

# Requirements

- Node.js 20+
- npm

---

# Installation

Clone the repository

```bash
git clone <repository-url>
cd frontend
```

Install dependencies

```bash
npm install
```

---

# Environment Variables

Create a `.env` file.

```env
VITE_API_URL=http://localhost:3000
```

---

# Run the application

Development

```bash
npm run dev
```

Production

```bash
npm run build
npm run preview
```
